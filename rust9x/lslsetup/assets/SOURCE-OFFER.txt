PRIMARY SOURCE DISTRIBUTION
---------------------------

For every release of this software, a source archive containing the
complete corresponding source code for all vendored third-party binaries
is attached to the GitHub release page:

  https://github.com/gmatht/lsl-usb/releases

Look for the asset named:
  lslsetup-vendored-src-VERSION.tar.gz

This archive includes:
  - grub4dos source at the exact git commit used to build BOOTX64.EFI
  - Ubuntu shim source package (.dsc + .orig.tar.* + .debian.tar.xz)
  - Ubuntu GRUB2 source package (.dsc + .orig.tar.* + .debian.tar.xz)

If the release attachment is unavailable, the exact upstream locations
are listed below.  Should those upstream sources also become
unavailable, a complete source archive can be requested by opening an
issue at the project repository (see link above).

This offer is valid for a period of not less than three (3) years from
the date of distribution of this software.

---------------------------
